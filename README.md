Somalia Inflation and Economic Growth Analysis (2013–2023)

Project Overview

This project examines the relationship between inflation and economic growth in Somalia from 2013 to 2023. It explores whether changes in inflation are associated with changes in GDP growth using economic data analysis and statistical methods.

The project applies Python for data cleaning, exploratory data analysis (EDA), data visualization, and Ordinary Least Squares (OLS) regression. The objective is to understand the direction and strength of the relationship between inflation and economic growth and interpret the findings from an economic perspective.

Research Question

Is inflation negatively or positively associated with economic growth in Somalia between 2013 and 2023?

Project Objectives

* Analyze inflation and GDP growth trends in Somalia.
* Explore the relationship between inflation and economic growth.
* Visualize annual economic trends and the relationship between the two variables.
* Apply OLS regression to estimate the relationship.
* Interpret the statistical results and discuss the limitations of the analysis.

Tools and Technologies

* Python – Data analysis and statistical modeling.
* Pandas – Data cleaning and manipulation.
* Matplotlib – Data visualization.
* Statsmodels – OLS regression analysis.
* Git and GitHub – Version control and project documentation.

Methodology

The analysis follows these steps:

1. Import and inspect the economic dataset.
2. Clean and prepare the data for analysis.
3. Conduct exploratory data analysis.
4. Create visualizations to examine annual trends and relationships.
5. Apply OLS regression, using inflation as the independent variable and GDP growth as the dependent variable.
6. Interpret the findings and discuss the limitations.

Key Findings

The preliminary regression results indicate a negative association between inflation and GDP growth.

* Inflation coefficient: -0.8255
* R-squared: 0.177
* P-value: 0.198

The estimated coefficient suggests that a one-percentage-point increase in inflation is associated with an estimated 0.8255-percentage-point decrease in GDP growth in this sample.

However, the relationship is not statistically significant at the 5% level. The findings should therefore be interpreted cautiously and do not establish a causal relationship.

Limitations

* The analysis uses only 11 annual observations.
* Other factors affecting economic growth are not included in the model.
* The regression identifies association, not causation.
* Further analysis with more observations and additional economic variables would improve the research.
